# Tolon 0.1.0-beta.2

The second beta, built from what the first testers reported. Thank you for the photos.

## Fixed

- **The reminder covers every display again.** After the settings window had been opened once, a reminder could show on one display only, with a warning about keyboard focus. Tolon now returns to its background mode reliably before each reminder.
- **A display that disappears while a reminder is up.** Its window is hidden instead of being left on screen.
- **A long calendar error no longer squeezes the calendar name** out of the Calendars list.

## New

- **Rooms on the reminder.** The meeting location shows under the time, with or without a call link. Google's generated room names ("Building-1-Room (8) [Google Meet]") are reduced to the room, so you read "Room", not the whole label.
- **Skip events without a call link.** A new rule in Settings, Rules, off by default: personal blocks and plain appointments stay quiet, meetings with a link or an event page still remind you.
- **Google public address hint.** Pasting a Google Calendar public address now explains that only the secret address works, with a help page for Google Workspace accounts that hide it. [How to get the link](https://github.com/danielpsf/tolon/blob/v0.1.0-beta.2/docs/help/ical-links.md).

## Known limits

- Tolon is not signed by Apple or by a Windows certificate authority yet, so macOS and Windows ask you to confirm it once. The steps are below.
- Google Calendar sign-in is still to come. Until then, use Google's secret iCal address.
- Windows ships as the `-setup.exe` installer only.

Something wrong or confusing? [Open an issue](https://github.com/danielpsf/tolon/issues/new).
