Anonymised real-world feeds go here, one `.ics` per quirk (see docs/plan.md S2.1), each with `<name>.expected.json` generated by `cargo xtask fixtures` and reviewed by hand. Replace names, emails and UIDs; keep time zones, RRULEs, EXDATEs, overrides and line folding exactly as the source produced them.

The 12 files in this directory are synthetic: they copy the shape of Google and Outlook exports (property order, parameters, folding, VTIMEZONE blocks) with invented people, `example.com` addresses and hosts. Nothing here comes from a real calendar.

Snapshots are taken at a fixed clock, Thursday 22 Oct 2026 08:00 UTC, in the zone Europe/Berlin (`crates/tolon-core/tests/common/mod.rs`). The next seven days contain the end of summer time on Sunday 25 Oct. Under the default expand options, except `all-day.ics`, whose snapshot keeps the all-day events so their spans can be read; the default exclusion has its own test (AC2.4). Each snapshot also records the calendar name, the event count and the number of skipped components.

`huge-10000-events.ics` is not committed. 10,000 events are about 2 MB of text, so the test generates the feed in memory (one event every 3 hours from 1 Jun 2026, every 500th repeating weekly ten times) and only its snapshot is committed.

After any change to a feed or to expansion, run `cargo xtask fixtures` and read `git diff fixtures/` line by line before committing.
